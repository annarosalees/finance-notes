# finance-notes

🇯🇵 [日本語版](./README.md)

Introductory notes on how FX, CFD, and binary options actually work,
organized from a practitioner's perspective. The goal is to explain
what each product *is* and *why* it moves the way it does — without
leaning too heavily on jargon.

## Who this is for
- People who are about to start working in FX/CFD/derivatives operations
- Anyone who wants a systematic understanding of how these products work in practice

## Notes included
- `notes/cfd.md` (JP) / `notes/cfd.en.md` (EN) — CFDs (cash-settled
  contracts for difference): indices, commodities, US stocks, ETFs, etc.
- `notes/fx.md` — FX (margin foreign exchange trading) *planned*
- `notes/binary.md` — Binary options *planned*

## Structure of each note
Every note follows the same format:
1. What the product is
2. How its price and P&L are determined
3. How it's handled in practice (rate generation, covering, etc.)
4. Common points of confusion

## Note
- These notes are a personal study record intended to explain
  general financial knowledge. They contain no internal information
  specific to any company or system.
- This is not intended as investment advice.
