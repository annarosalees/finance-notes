# Quickstart: FXノートの検証手順

本featureには実行可能なアプリケーションがないため、「動かして確認する」
の代わりに、以下の手順でドキュメントとして成果物を検証する。

## 前提

- `notes/fx.md`, `notes/fx.en.md` が追加されている
- `README.md`, `README.en.md` の「収録ノート」欄が更新されている

## 検証手順

1. **4部構成の充足確認（SC-002, FR-001）**
   - `notes/fx.md` を開き、以下の4見出しが存在し、それぞれに実質的な
     本文（プレースホルダでない）があることを確認する。
     1. 商品概要（FXとは何か、`cfd.md`との関係）
     2. 価格・損益の仕組み（pips／レバレッジ／証拠金／スワップポイント）
     3. 実務上どのように扱われるか（レート生成・カバーディール）
     4. つまずきやすいポイント（3件以上）

2. **相互リンク確認（FR-002, Edge Case）**
   - `notes/fx.md` の商品概要節に `notes/cfd.md` へのリンクがあることを
     確認する（`cfd.md`未読の読者でも辿れること）。

3. **用語説明の確認（FR-003, SC-001）**
   - pips・レバレッジ・証拠金・スワップポイントの4用語がすべて平易な言
     葉で説明されているか確認する。

4. **つまずきポイントの具体性確認（FR-005, SC-003）**
   - 「つまずきやすいポイント」節に、スワップの正負・レバレッジ規制・
     週明け窓開けリスクを含む3件以上の具体的な注意点があるか確認する。

5. **日英パリティ確認（FR-008, SC-004）**
   - `notes/fx.md` と `notes/fx.en.md` の見出し（`##`）の数と順序を
     `grep -n "^##" notes/fx.md notes/fx.en.md` 等で突き合わせ、一致し
     ているか確認する。
   - 英語版に未翻訳部分がある場合、その旨が明示されているか確認する。

6. **constitution原則の遵守確認（FR-006, FR-007）**
   - 特定企業・システム名が含まれていないか（原則III）。
   - 「買うべき」等の断定的な売買推奨表現が含まれていないか（原則IV）。

7. **README更新確認（FR-009）**
   - `README.md` の「収録ノート」欄で `notes/fx.md` の表記が「※作成予定」
     からリンク付きの表記に変わっているか確認する。
   - `README.en.md` も同様に確認する。

## 期待結果

上記1〜7がすべて満たされていれば、本feature（FXノート新規作成）は完了
とみなす。
